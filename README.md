# App Store Success Analysis

End-to-end R workflow for cleaning Google Play Store data, engineering features, and answering 15 statistical/modeling questions about app success.

## Project Overview

This repository contains:
- Raw input data in `data/raw`
- Cleaning and preprocessing scripts
- A merged 15-question analysis pipeline
- Rendered report artifacts (`.html`, `.tex`, `.log`)
- Generated outputs (tables, model summaries, and plots) in `outputs`

## Data Sources

The project uses Google Play Store app and review datasets.

Original sources:
- https://www.kaggle.com/datasets/lava18/google-play-store-apps
- https://www.kaggle.com/datasets/prakharrathi25/google-play-store-reviews

Expected raw files:
- `data/raw/googleplaystore.csv`
- `data/raw/googleplaystore_user_reviews.csv`
- `data/raw/reviews.csv` (optional in current pipeline)

## Repository Structure

- `preprocessing/cleaning.R`: cleans app/review data and writes core cleaned datasets
- `preprocessing/analysis.R`: filters final data and writes `final_data_filtered.csv`
- `01_preprocessing.R`: standalone preprocessing script variant
- `merged_appstore_analysis_15_questions.R`: main integrated script (cleaning + feature engineering + Q1-Q15 outputs)
- `02_statistical_analysis.Rmd`, `appstore.rmd`, `modelling.Rmd`: R Markdown analysis documents
- `outputs/`: generated CSV/TXT summaries and model outputs
- `outputs/plots/`: generated figures for Q1-Q15

## Environment

Use R 4.x with these packages:
- `dplyr`
- `readr`
- `stringr`
- `ggplot2`
- `rmarkdown` (for rendering `.Rmd` files)

Install dependencies in R:

```r
install.packages(c("dplyr", "readr", "stringr", "ggplot2", "rmarkdown"))
```

## How to Run

From the repository root, run the integrated pipeline:

```bash
Rscript merged_appstore_analysis_15_questions.R
```

This script performs:
1. Raw data loading
2. Cleaning and deduplication
3. Sentiment summary merge
4. Feature engineering
5. Statistical tests and regression/logistic models
6. Export of Q1-Q15 outputs and plots

Optional step-by-step run:

```bash
Rscript preprocessing/cleaning.R
Rscript preprocessing/analysis.R
```
